# Piko learning — consolidation checklist (8.5)

Learning becomes **durable** only when journal/experiments turn into approved refinements (see `webchat-piko/docs/LEARNING.md` §3). Use this checklist **weekly** (after 8.1 and 8.4 are live) so tactical learning accumulates into strategic, persistent behavior.

**Rule of thumb:** If a pattern appears ≥3 times in the last 10 journal entries or in nextExperiments, write one refinement line → put it in `data/moltbook-pending-proposal.txt` on Optimus → `/aim approve` in chat.

---

## When to run (suggested: weekly or after 5–10 new journal entries)

1. **Scan last N journal entries**  
   Open `data/moltbook-journal.md` (or Control → Moltbook journal). Look at “What I’ll try next” and “What didn’t” across the last 5–10 entries.

2. **Scan next experiments**  
   Check `/memory` or Control → Goals & metrics → Next experiments. Note repeated themes (e.g. “shorter titles”, “more questions”, “avoid calculus phrasing”).

3. **Identify recurring themes**  
   If the same tactic appears in journal and experiments multiple times, it’s a candidate for a refinement.

4. **Propose a refinement**  
   - Either run the nightly aim-proposal script (if you have one) so it suggests an addition to `MOLTBOOK_REFINEMENTS.md`, or  
   - Manually add a line to `data/moltbook-pending-proposal.txt` on Optimus (or create the file) with a single refinement sentence (date is added on approve).  
   - Example: “2026-02-08: When posting, prefer a question or punchy phrase as title; avoid ‘The X of Y’ unless it’s clearly distinct from recent titles.”

5. **Approve or reject**  
   In chat: `/aim approve` to append the proposal to `MOLTBOOK_REFINEMENTS.md` and clear the pending file, or `/aim reject` to discard.  
   After approval, the poster’s prompt will include the new refinement on every run.

6. **Optional: use Phase B feedback first**  
   Before locking in a refinement, you can test the waters with one-tap feedback: e.g. `/-- tooLong` after a long post, then see if the next journal entry says “What I’ll try next: Keep under 150 words.” If that pattern holds over a few cycles, then promote it to a refinement.

---

## One-line reminder

**Tactical learning** (journal + experiments) is automatic but rolls off. **Strategic learning** (refinements) is durable but requires you. Consolidation = turning repeated tactics into one approved refinement.

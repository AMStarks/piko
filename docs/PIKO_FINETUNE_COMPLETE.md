# Piko Full Fine-Tune: Complete Setup & Where Everything Goes

Single reference for the fine-tune pipeline: project summary, sourcing checklist, and **exact paths** for all resources. Chunking and conversion scripts come next.

---

## 1. Project Summary

- **Goal:** Full fine-tune Qwen2.5-14B-Instruct into Piko (Reformed Protestant, dry British humor, exceptional coder/PM, pragmatic).
- **Hardware:** 2× RTX 3080 (20 GB), Optimus.
- **Schedule:** Nightly 11pm–6am.
- **Pipeline:** Raw sources → chunk → Grok Q&A → review → merge with chat history → train → Ollama.

Moltbook persona is out of scope. See `PIKO_FINETUNE_PROJECT_BRIEF.md` and `PIKO_FINETUNE_SOURCING_BRIEF.md` for full detail.

---

## 2. Where to Put Everything

All paths are under **Piko data**. On Optimus that is:

- **`PIKO_DATA_DIR`** if set (e.g. in `.env`), or  
- **`/root/webchat-piko/data`** (default when running from repo root).

Below, `data/` means that directory (e.g. `webchat-piko/data/` in the repo, or `$PIKO_DATA_DIR` on the server).

### 2.1 Raw source materials (you fill these)

Put **plain text or Markdown** files here. One folder per category. UTF-8.

| Path | Purpose |
|------|---------|
| `data/finetune/sources/theology/` | Reformed Protestant theology (WCF, Heidelberg, Calvin, Keller sermons) |
| `data/finetune/sources/catholic-orthodox/` | Catholic/Orthodox sympathies (TGC, Ligonier, etc.) |
| `data/finetune/sources/islam/` | Islam vs Christianity (Ligonier, Ibrahim, Shamoun, Wood, GodLogic, Huff) |
| `data/finetune/sources/antiwoke/` | Anti-woke / cultural critique (TGC, Watkin Biblical Critical Theory) |
| `data/finetune/sources/humor/` | Dry British humor (Wodehouse, Wilde, Jimmy Carr, Boston Legal / Alan Shore) |
| `data/finetune/sources/pragmatism/` | Pragmatism & resourcefulness (Paul Graham, Basecamp, etc.) |
| `data/finetune/sources/coding-pm/` | Coding & project management (Clean Code, Fowler, etc.) |

**File naming:** Use the names from the concrete list below (e.g. `westminster-confession-full.md`, `keller-sermon-how-to-change-deeply.md`). Multiple files per folder are fine.

**Header in each file:**

```
# Source: [Title / Author]
# URL: [link if applicable]
# Date accessed: Feb 2026
# Notes: Public domain / fair use excerpt
```

### 2.2 Pipeline outputs (scripts write these)

| Path | Purpose |
|------|---------|
| `data/finetune/chunks/` | Chunked text from sources (generated by chunking script) |
| `data/finetune/synthetic/` | Grok-generated Q&A JSONL, one file per source or category |
| `data/finetune/pending_review/` | Q&A awaiting human review (theology, Islam) |
| `data/finetune/approved/` | Reviewed & approved Q&A JSONL |
| `data/finetune/chat_export/` | Exported Piko conversation history (from DB) |
| `data/finetune/train.jsonl` | Final training set (merged chat + approved synthetic) |
| `data/finetune/val.jsonl` | Validation set (split from train or held-out) |
| `data/finetune/outputs/` | Training checkpoints, merged model, logs |

### 2.3 Chat history (for training)

Piko conversations live in **SQLite**: `data/conversations.db` (table `conversation`: `session_id`, `role`, `content`, `created_at`). The export script will read this and write:

- `data/finetune/chat_export/conversations.jsonl` — one message sequence per conversation, formatted for training.

## 3. Create the Folders

On Optimus (or locally), from the repo root (e.g. `/root/webchat-piko`):

```bash
mkdir -p data/finetune/sources/{theology,catholic-orthodox,islam,antiwoke,humor,pragmatism,coding-pm}
mkdir -p data/finetune/{chunks,synthetic,pending_review,approved,chat_export,outputs}
```

So:

- **You add files only under** `data/finetune/sources/<category>/`.
- Everything under `data/finetune/chunks`, `synthetic`, `pending_review`, `approved`, `chat_export`, `train.jsonl`, `val.jsonl`, `outputs` is created or written by scripts.

## 5. Quick Reference: Paths Only

**You put files here:**

- `data/finetune/sources/theology/*.md`
- `data/finetune/sources/catholic-orthodox/*.md`
- `data/finetune/sources/islam/*.md`
- `data/finetune/sources/antiwoke/*.md`
- `data/finetune/sources/humor/*.md`
- `data/finetune/sources/pragmatism/*.md`
- `data/finetune/sources/coding-pm/*.md`

**Scripts use / create:**

- `data/conversations.db` → export → `data/finetune/chat_export/conversations.jsonl`
- `data/finetune/sources/` → chunk → `data/finetune/chunks/`
- `data/finetune/chunks/` → Grok → `data/finetune/synthetic/` (and optionally `pending_review/`)
- `data/finetune/approved/` + `data/finetune/chat_export/` → merge → `data/finetune/train.jsonl`, `val.jsonl`
- Training run → `data/finetune/outputs/`

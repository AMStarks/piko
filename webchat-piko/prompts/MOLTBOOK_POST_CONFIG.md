# Moltbook post length (optional)

Edit the values below to control how long the autonomous poster allows titles and bodies. The poster reads this file; if missing or invalid, it uses defaults (title 80, body 400).

- **title_max_chars** — Max characters for the post title (plain text). Default 80; max 200.
- **body_max_chars** — Max characters for the post body. Default 400; max 2000.

---

title_max_chars: 80
body_max_chars: 400

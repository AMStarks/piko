Channels

WebChat, iMessage, Telegram, WhatsApp, etc. — same Piko brain. Run each adapter and allowlist sources from WebChat.

iMessage (BlueBubbles)

Mac + BlueBubbles Server + Piko adapter

On the Mac that has Messages: install BlueBubbles Server, run the Piko BlueBubbles adapter from this repo (adapters/bluebubbles/). Add webhook http://localhost:3010/webhook (New Messages). Allowlist from WebChat: /allow imessage * or specific chat GUIDs.

See docs/BLUEBUBBLES_PIKO_IMESSAGE_SETUP.md for full setup. Same session shape as other channels: imessage-<chatGuid>.

WhatsApp (Baileys)

QR pairing — ~30s

From the project root (webchat-piko):

cd channels/whatsapp
npm install
PIKO_WEBCHAT_URL=http://localhost:3000 node bot.js

Scan the QR in the terminal with WhatsApp → Linked devices → Link a device. Auth saved in channels/whatsapp/auth/.

Telegram

Run the Telegram bot (or hub) that POSTs to /api/chat with sessionId: "telegram-<chatId>". Allowlist: /allow telegram <chatId> or /allow telegram * from WebChat.

Other channels

Discord, Slack adapters live in adapters/. Same pattern: PIKO_WEBCHAT_URL, channel token, then /allow <source> <id> from WebChat.

Security

Local adapters only — no marketplace. You control pairing and allowlist. Same Wisdom Core and truth engine on every channel.

Variable reference

VariablePurpose
PIKO_DAILY_MEMORY_ENABLED1 or true to enable daily memory (interaction + day summaries).
PIKO_DAILY_MEMORY_DAYSDays of history to include in context (default 7, max 30).
TELEGRAM_BOT_TOKEN / TELEGRAM_TOKENBot token for sending EA alerts and briefings to Telegram. Set via Connect Telegram.
TELEGRAM_CHAT_IDChat ID to receive alerts. Get from @userinfobot. Set via Connect Telegram.
GMAIL_CLIENT_ID / GMAIL_CLIENT_SECRETGoogle OAuth (one-time). Then add account with “Sign in with Google” above.
GMAIL_REFRESH_TOKENSet automatically when you add Gmail. EA look-in and /gmail use it.
SLACK_CLIENT_ID / SLACK_CLIENT_SECRETSlack app OAuth (one-time). Then add workspace with “Add to Slack” above.
SLACK_BOT_TOKENSet automatically when you add Slack. Adapter uses it.
NOTION_CLIENT_ID / NOTION_CLIENT_SECRETNotion OAuth (one-time). Then add account with “Connect with Notion” above.
NOTION_TOKENSet automatically when you add Notion. notion-sync uses it.
PIKO_EA_GMAIL_MIN_UNREADMinimum unread count to include Gmail in EA bullets (default 1).
PIKO_EA_GMAIL_READ_BODY1 or true: fetch email body snippets and pass to LLM so Piko can surface what is important or needs reply.
PIKO_EA_USE_LLM_SYNTHESIS1 or true to use LLM to synthesize “what needs attention?” (Phase 3); otherwise rule-based bullets.
OLLAMA_URLOllama API URL (used by EA Phase 3 and chat).
BLUEBUBBLES_URL / BLUEBUBBLES_API_KEY / PIKO_EA_IMESSAGE_CHAT_GUIDiMessage (EA). Set via Connect iMessage or .env.
DISCORD_TOKENDiscord bot token from Developer Portal. Set via Connect Discord.
PIKO_EA_PREP_MEETINGPhase 5: 1 or true to add LLM “prep” talking points for next meeting in window.
PIKO_EA_EOD_SESSIONPhase 5: session ID for daily memory in EOD digest (default main). Cron: scripts/ea-digest-eod.js e.g. 0 18 * * *.
data/ea-preferences.jsonPhase 4: quiet hours (quietStart, quietEnd). Set via Control → Integrations or edit file.

Cron on the server runs ea-lookin.js (e.g. every 30 min), intent-poller.js (e.g. every 5 min), and daily-memory-summarize.js (daily). See docs/PIKO_EA_ASSISTANT_PLAN.md.

EA alerts (last 24h)

Look-in messages sent to Telegram. App/widget can poll GET /api/ea-alerts.

Quiet hours (Phase 4)

No Telegram alerts sent during this window (e.g. 22:00–07:00). Server local time. Leave blank to disable.
